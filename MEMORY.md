Clip Miner: fungsinya menambang momen terbaik dari podcast YouTube orang lain untuk clipping. Pipeline: topik -> discovery -> Episode Opportunity Score (gate biaya, episode di bawah threshold tidak pernah ditranskrip) -> transcript -> deteksi momen 15-90s -> scoring 10 dimensi -> threshold tier (95+ Publish Immediately, 90-94 High Priority, 85-89 Good Candidate, 80-84 Optional, <80 Archive) -> export CSV/TXT. Skor bukan rata-rata tertimbang: 0.55 * mean(2 driver terkuat) + 0.45 * weighted(standalone/clarity/hook), lalu quality caps. Confidence dipisah dari skor; heuristic engine di-cap 82%.

Clip Miner transcript: rantai provider berurutan lewat TRANSCRIPT_PROVIDERS (default hosted,ytdlp,captions,stt). Dari IP datacenter semua jalur gratis diblokir (scrape balik HTTP 200 body 0 byte; yt-dlp default minta PO token), TAPI homelab pakai IP residensial jadi yt-dlp kemungkinan besar jalan gratis — uji dulu sebelum bayar vendor: docker compose exec app npx tsx scripts/diagnose-transcript.ts <videoId>. Kalau ytdlp sukses, set TRANSCRIPT_PROVIDERS=ytdlp,captions dan tidak perlu langganan. yt-dlp sudah ter-bundle di image (pinned, update kalau ekstraksi mulai gagal). Vendor berbayar dipilih dari UI (AI Agents -> Transcript vendor), bukan env; Supadata adalah satu-satunya preset terverifikasi dan endpoint universalnya balas job ID untuk video panjang.
